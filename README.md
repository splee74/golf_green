# 그린 리더

휴대폰 기울기 센서로 그린 경사를 재고, 퍼팅 조준점과 세기를 계산하는 웹앱(PWA)입니다. 안드로이드 Chrome 기준으로 만들었습니다.

## 기능
- **수평계**: 폰을 그린에 놓으면 경사(%)와 내리막 방향을 실시간으로 보여줍니다. 2초 정밀 측정도 됩니다.
- **퍼팅 읽기**: 거리와 그린 스피드를 넣고, 퍼팅 라인 위 1~3곳에서 경사를 잽니다(**폰 위쪽이 홀을 향하게**). 그러면 아래를 알려줍니다.
  - 조준점 (예: "홀 오른쪽 컵 2.0개 (22cm)")
  - 세기 (평지 몇 m 퍼팅처럼 칠지)
  - 예상 공 경로 그림
- **센서 보정**: 같은 자리에서 폰을 180° 돌려 두 번 재면 케이스나 센서 오차가 없어집니다.
- 센서가 없으면 경사값을 직접 입력할 수 있습니다.
- 오프라인에서도 동작합니다(서비스 워커). 홈 화면에 설치할 수 있습니다.

## 파일
| 파일 | 내용 |
|---|---|
| `physics.js` | 공 굴림 시뮬레이션과 조준점·세기 계산 (2변수 뉴턴법) |
| `app.js` | 센서 처리, 화면 |
| `index.html`, `style.css` | 화면 구성 |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA (설치, 오프라인) |

## 계산 모델
- 그린 스피드(스팀프, m) → 구름 저항 감속도 `a = 1.83² / (2 × 스팀프)`
- 경사에 의한 가속 = `5/7 × g × 경사` (굴러가는 공)
- 측정 지점 사이의 경사는 선형 보간합니다.
- 공이 **홀 중심을 지나 설정 거리(기본 40cm)만큼 더 가서 멈추는** 방향과 세기를 찾습니다.
- 잔디 결, 바람, 젖은 정도는 반영되지 않습니다.

## 휴대폰에서 실행하기
안드로이드 Chrome은 **HTTPS 주소에서만** 기울기 센서를 허용합니다.

### A. 바로 테스트 (PC와 폰이 같은 Wi-Fi)
1. PC에서: `python -m http.server 8765` (이 폴더에서 실행)
2. PC IP 확인: `ipconfig` → 예: 192.168.0.10
3. 폰 Chrome 주소창에 `chrome://flags/#unsafely-treat-insecure-origin-as-secure` 입력
   → `http://192.168.0.10:8765` 추가 → Enabled → 재시작
4. 폰에서 `http://192.168.0.10:8765` 접속

### B. 골프장에서 쓰기 (HTTPS 무료 호스팅)
GitHub Pages, Netlify, Cloudflare Pages 중 하나에 이 폴더를 그대로 올리면 됩니다.
폰에서 접속한 뒤 Chrome 메뉴 → **홈 화면에 추가**를 누르면 앱처럼 설치되고, 오프라인에서도 열립니다.

> 파일을 고친 뒤에는 `sw.js`의 `VERSION`을 올려야 폰에 새 버전이 반영됩니다.
